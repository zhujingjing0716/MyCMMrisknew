# Cardiometabolic Multimorbidity Risk Assessment System

A machine learning-based risk assessment tool for cardiometabolic multimorbidity.

## Key Features

⦁    Individualized risk assessment

⦁    Batch prediction capability

⦁    User-friendly interactive interface

## Technology Stack

* Streamlit
* Scikit-learn
* LightGBM
* Pandas \& NumPy
